# Zero-Trust Enclave Vault 🛡️

A hardened cryptographic secrets engine engineered for zero-trust microservice meshes, providing hardware-backed envelope encryption, dynamic lease generation, and Shamir threshold unsealing.

## Key Capabilities
- **Envelope KMS Encryption:** DEK (Data Encryption Key) / KEK (Key Encryption Key) architecture over AES-256-GCM.
- **Threshold Unsealing:** k-of-n Shamir's Secret Sharing for root key initialization.
- **mTLS Service Attestation:** Cryptographic workload verification preventing lateral credential leakage.
